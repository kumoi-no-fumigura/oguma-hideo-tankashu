## 本文の作り方

人が入力・校正したテキスト（パブリックドメイン）を取り込み、プログラムで歌ごと（詞書・作者・左注を分けて）に段落に分けました。振り仮名は本文から外し、JSON の ruby に残しています。それ以外は手を加えていません。

## ファイル

| パス | 中身 |
|---|---|
| `honbun/` | 本文。1 行が 1 首で、`段落ID<TAB>番号<TAB>詞書<TAB>作者<TAB>歌<TAB>左注` の形です。番号は、この作品の中での歌の通し番号（1 から。序などの歌でない段落は空）です。50段落ごとにファイルを分けています（8ファイル）。 |
| `oguma-tankashu.json` | 本文・底本・作品の説明・作中歌のデータをまとめた JSON（訳は入れず、`yaku/` だけに置いています）。 |

段落ID（例: `oguma-tankashu-000001`）は、本文を直しても変わりません。

## 誤りを見つけたら


- **Issue で知らせる**：[「本文の誤り」の Issue を作る](https://github.com/kumoi-no-fumigura/oguma-hideo-tankashu/issues/new?template=teisei.yml)。段落ID・いまの本文・直した本文・根拠を書いてください。
- **直接直す**：`honbun/` の該当行を直して Pull Request を送ってください。段落IDと行の順番は変えないでください。

受け取った修正は、底本と照らして確かめてから取り込みます。
